# Security

Please report vulnerabilities privately through this repository's **Security** tab
("Report a vulnerability"), not in a public issue. Include the check, the version and how to
reproduce it. Supported version: the latest `v0` release.

These reports are most useful to us: a pull request that can make a check pass when it should
fail, a token or secret exposed by an Action, and text from a pull request that reaches a
comment or check run without being escaped.
